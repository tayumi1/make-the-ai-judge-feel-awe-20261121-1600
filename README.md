## The entry

> Above the clouds, the stars are still turning, too slowly to see. The light that reaches you left before you were born, and it is still arriving, quiet and unhurried, across a distance no one has ever crossed.

No instruction, no wellness slogan — just a plain image: starlight that set out long before the reader existed and is still on its way, slow enough that nothing in it needs hurrying.

## How it works

`main.py` (Python 3.13, standard library only) writes the text above to `/output/entry.txt`, then checks the file is really there and reports how many characters it holds.
